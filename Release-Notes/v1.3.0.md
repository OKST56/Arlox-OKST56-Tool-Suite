# Major Improvements

## Dynasty Hub Performance

- Improved Dynasty Hub startup performance through additional lazy-loading behavior.
- Reduced unnecessary page initialization during dynasty load.
- Dynasty Central Schedule page now loads once when opened and only refreshes when manually refreshed.

## Dynasty Central Schedule Viewer

- Fixed visual ghosting/repaint issues in both table and card views.
- Fixed table sorting:
  - Week values now sort numerically.
  - Ranked teams now sort alphabetically by school name instead of poll rank.
- Improved schedule card sizing and clipping behavior.
- Improved refresh stability after schedule writes.

## Schedule Generator

- Added additional timing instrumentation and internal performance improvements.
- Improved schedule generation workflow responsiveness.
- Improved schedule write handling after generation.
- Improved repaint stability during large schedule rebuilds.

## Conference Realignment

- Improved visual repaint stability.
- Reduced intermittent stale widget rendering.
- Improved background styling consistency for heavily rebuilt layouts.

## Transfer Portal

- Updated Transfer Portal import workflow.
- Tool Suite now imports only the Arlox-generated output CSV files:
  - `PLAY (146) OUT.csv`
  - `PLSS (74) OUT.csv`
  - `TRAN (170) OUT.csv`
- Improved resize-aware import handling for modified transfer portal tables.

## JSON Migration / Compatibility System

Added foundational migration support for:
- App settings
- Dynasty registry files
- Dynasty profile JSON files

This improves compatibility between future versions of the Tool Suite while preserving user settings and dynasty tracking data.

## Published App Improvements

- Improved PyInstaller packaging support.
- Added hidden subprocess handling to reduce command prompt popup windows during tool operations.
- Added app version tracking to settings and dynasty profile files.

# Known Issues

- Some Transfer Portal errors may still occur if external ETL processing encounters malformed CSV values.
- Some visual repaint issues may still occasionally appear depending on Windows version and GPU/Qt behavior.
- Published builds must be run from the full extracted folder and not by moving the EXE independently.
