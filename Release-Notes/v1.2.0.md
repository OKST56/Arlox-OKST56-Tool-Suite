# Arlox-OKST56 Tool Suite – Release v1.2.0

## Overview

Version 1.2.0 is a major development release focused on Schedule Generator performance, Kickoff Classic support, Conference Realignment stability, Dynasty Central customization, and expanded file compatibility.

This release introduces true neutral-site Kickoff Classic support, improves schedule write speed, and adds several quality-of-life improvements throughout the app.

---

## Schedule Generator

### Kickoff Classic Promotion System

Kickoff Classics are now created by promoting existing Week 0 and Week 1 nonconference games rather than generating separate matchups.

Eligible games are scored using criteria such as:
- Ranked vs ranked
- Ranked vs Power conference opponent
- Power vs Power
- Week 0 preference
- Rivalry showcase bonus

Selected games are automatically:
- Marked as `kickoff_classic`
- Converted to neutral-site games
- Assigned a configured stadium SGID

### Dynamic Kickoff Classic Stadium Settings

The Kickoff Classic settings page now supports:
- Adding neutral-site stadiums
- Removing stadiums with a red X button
- Saving any number of configured stadiums

Each configured stadium can create one Kickoff Classic game.

### NEUT and NESG Table Support

When schedules are written to the save file, the app now rebuilds both:
- `NEUT`
- `NESG`

These tables are populated from promoted Kickoff Classic games so that neutral-site logos and presentation data appear correctly in the in-game UI.

### Schedule Write Performance Improvements

Schedules are now written by:
1. Building a full SCHD import CSV
2. Importing the rebuilt CSV into the save file

This replaces hundreds of individual native bridge write calls and significantly improves schedule write speed.

### CSV Import Flexibility

The DB Editor and internal import systems now support CSV imports with fewer rows than the existing database table.

This allows tables such as SCHD, DIVI, NEUT, and NESG to shrink safely during import.

## Conference Realignment

### Division Management Overhaul

The Manage Divisions dialog now supports:
- Adding new divisions
- Renaming divisions
- Deleting divisions
- Creating multiple divisions without closing the window

### Automatic DIVI Cleanup

When Apply Changes is used:
- Divisions with zero assigned teams are removed from the `DIVI` table
- Dormant divisions are no longer retained

This prevents empty divisions from appearing in the in-game conference standings UI.

### Independents Boundary Rule Exception

The 11-team/12-team boundary warning is now bypassed for Independents, CGID 5.

This allows users to move teams into and out of Independents freely.

---

## Dynasty Central

### Schedule Viewer Settings Page

A new Settings page has been added to Dynasty Central.

Users can now configure:
- Cards per row: 2, 3, or 4
- Schedule table font size

### Schedule Table Improvements

The Schedule table now supports:
- Column sorting
- Column resizing
- Auto-fit columns on load
- Stretching the Location column
- Vertical header separators
- Correct day-of-week sorting

### Team Logo Folder Support

Dynasty Central now uses the selected dynasty team logo folder instead of always defaulting to CFBR logos.

Logo caching now includes both the logo number and the active logo directory to prevent stale logos.

---

## File Compatibility

### RPCS3 USR-DATA Support

Users can now open extensionless `USR-DATA` files directly.

When an extensionless file is selected, a warning dialog explains:
- RPCS3 usage requirements
- PS3 and Xbox 360 decryption requirements
- Risks of editing unsupported file types

This support has been added to:
- Dynasty Hub
- DB Editor
- Utility tools
- Dynasty Folder loading

## Mod Presets

### 2002 Retro Mod

Added a new `2002 Retro Mod` preset.

For this release, it inherits:
- Protected rivalry defaults from College Football Revamped
- Conference scheduling policies from College Football Revamped

This provides a functional starting point for future customization.

## Packaging and Performance

### Onedir Build Support

The app can now be packaged using PyInstaller `--onedir` mode, improving startup speed and reducing delays caused by onefile extraction.

### Native Bridge Optimization Direction

The new CSV-based schedule write pipeline reduces calls to the external native helper executable and improves write performance.
