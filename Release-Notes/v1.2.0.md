## Overview

Version 1.2.0 is a major update focused on Schedule Generator performance, Kickoff Classic support, Conference Realignment stability, Dynasty Central customization, and expanded file compatibility.

This release introduces true neutral-site Kickoff Classic support, dramatically improves schedule write speed, and adds a large number of quality-of-life improvements across the application.

---

## Major Additions

### Kickoff Classic Support
- Kickoff Classics are now created by promoting existing Week 0 and Week 1 nonconference games.
- Each configured stadium can host one Kickoff Classic game.
- Games are automatically converted to neutral-site matchups.
- Kickoff Classic games now populate the `NEUT` and `NESG` tables so logos and presentation data appear correctly in-game.

### Dynamic Kickoff Classic Stadium Settings
- Add or remove any number of Kickoff Classic stadiums.
- Red X button removes configured stadiums.
- Number of kickoff games is now determined dynamically by the number of configured stadiums.

### RPCS3 USR-DATA Support
- Extensionless `USR-DATA` files can now be opened directly.
- Warning dialog explains safe usage and corruption risks.

### 2002 Retro Mod Preset
- Added a new mod preset.
- Currently inherits protected rivalries and conference scheduling policies from College Football Revamped.

---

## Schedule Generator Improvements

### Dramatically Faster Schedule Writes
Schedules are now written by rebuilding and importing a SCHD CSV rather than writing each game individually.

### CSV Import Flexibility
The application now supports importing CSV files with fewer rows than currently exist in the database.

### Schedule Validation
The built-in validator continues to detect:
- Under-scheduled teams
- Over-scheduled teams
- Team-week collisions

### Clear Schedule Memory
Allows users to clear generated schedules from memory without restarting the application.

---

## Conference Realignment Improvements

### Division Management Overhaul
- Add, rename, and delete divisions.
- Create multiple divisions without closing the dialog.
- Empty divisions are automatically removed from the DIVI table.

### Independents Exception
The 11-team/12-team boundary warning is now bypassed for Independents (CGID 5).

---

## Dynasty Central Improvements

### Schedule Viewer Settings
Users can now customize:
- Cards per row (2, 3, or 4)
- Schedule table font size

### Schedule Table Enhancements
- Sortable columns
- Resizable columns
- Auto-fit columns on load
- Location column stretches to fill remaining space
- Correct Monday through Sunday sorting
- Vertical header separators

### Team Logo Support
Schedule Viewer now uses the selected dynasty team logo folder instead of always defaulting to CFBR logos.

---

## File Compatibility Improvements

Support for extensionless `USR-DATA` files has been added to:
- Dynasty Hub
- DB Editor
- Utility tools
- Dynasty Folder loading

---

## Performance Improvements

### Onedir Build Support
PyInstaller `--onedir` builds significantly improve application startup time.

### Reduced Native Bridge Calls
The new CSV-based workflow reduces dependency on repeated native helper calls.

---

## Known Issues

- Kickoff Classic RLID mappings are only partially confirmed.
- Schedule generation may still occasionally require regeneration.
- Some custom mod conference scheduling policies may need additional tuning.
