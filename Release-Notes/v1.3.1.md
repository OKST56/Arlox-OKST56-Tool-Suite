## Release Type

Hotfix release

## Summary

v1.3.1 is a hotfix focused on improving usability for users running Windows display scaling above 100%, especially 125% and 150%.

This release addresses UI clipping problems where wide pages could extend beyond the visible window area, causing the right side of the app to become inaccessible.

## Major Changes

### Fixed

- Fixed issue where wide app pages could be clipped on the right side when Windows display scaling was set to 125% or 150%.
- Fixed missing `QSizePolicy` import after adding responsive sizing behavior.
- Reduced layout problems caused by fixed-width or fixed-size widgets on scaled displays.

### Improved

- App now opens maximized by default to better support scaled displays and smaller screens.
- Added horizontal scrolling support where wide content may exceed the visible page width.
- Improved flexible sizing behavior for toolbox cards and wide UI panels.
- Improved shared scroll-area behavior through reusable UI helper functions.

## Primary Areas Updated

- Main App Window
- Dynasty Hub
- Dynasty Central
- Schedule Generator
- Conference Realignment
- Toolbox / Utilities

## Known Issues

- Some pages may still require additional layout refinement for very small screens or extreme display scaling.
- Horizontal scrolling is a hotfix safety improvement, not a full responsive redesign.
- Some dialogs and tables may still need future scaling cleanup.
